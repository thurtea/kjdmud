kjdmud is developed in git. Clone the repository and build with CMake. There is no separate stable / development branch split yet; main is the current tree.

  • Source on GitHub https://github.com/thurtea/kjdmud
  • Clone 
    git clone https://github.com/thurtea/kjdmud.git
cd kjdmud
  • Build and test 
    cmake -B build -S .
cmake --build build -j"$(nproc)"
ctest --test-dir build --output-on-failure
    Full dependency lists and connect steps are in INSTALL.md.
  • Run the bundled mudlib 
    ./build/kjdmud etc/driver.cfg
    Telnet on port 1122, WebSocket on port 1124. Use the Web Client against ws://127.0.0.1:1124.
kjdmud is an independent LPC driver. It is not affiliated with FluffOS, LDMud, or DGD.

Overview

kjdmud is a virtual machine, a network server, and a compiler for the LPC language. It is a from-scratch game driver written in C++20: lexer, parser, bytecode compiler, object system, and call_out / heart_beat scheduler.

Players connect over plain telnet, telnet over TLS, or WebSocket. The primary dialect target is FluffOS-style LPC. The dialect config switch can also select LDMud. A small bundled mudlib ships so the driver can boot and be tested.

Features

The goal is a stable, clean, testable driver. Current capabilities include:

Runtime

  • C++20 host with an LPC-only mudlib layer
  • Bytecode VM, object system, call_out and heart_beat
  • Regression suite run with CMake / CTest

Language

  • FluffOS dialect as the primary compatibility target
  • LDMud dialect selectable via config
  • Standard LPC types, applies, and a growing efun surface

Networking

  • Multi-port listen table (telnet and WebSocket)
  • TLS on marked listen ports
  • Connection encoding (default UTF-8) and GMCP

Persistence and tooling

  • FluffOS-style save_object write path
  • SQLite-backed database efuns
  • Public site and browser WebSocket client under website/

Source and issue tracking live on GitHub. Build instructions are in Documentation.

kjdmud is an independent LPC driver. It is not affiliated with FluffOS, LDMud, or DGD.

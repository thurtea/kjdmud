Web Client

Browser path onto a running kjdmud process. The driver does not serve this page. Open it from GitHub Pages, from a local static server, or as a file. Default listen port for WebSocket is 1124 (etc/driver.cfg).

  • 1122 telnet (Mudlet / tin / nc, not this page)
  • 1124 websocket (this page, default)
  • 1126 telnet + TLS
  • 1128 websocket + TLS (wss://127.0.0.1:1128 after certs)

Not connected

Local driver tip: python3 -m http.server 8080 --directory website then open http://127.0.0.1:8080/client.html while ./build/kjdmud etc/driver.cfg is running.
